# Swimlane / 泳道多主体流程

按角色、模块或数据来源划分责任泳道

## Structural family

Swimlanes / multi-actor flow

## Best for

- 实验-模拟-验证
- 部门协作
- 人机流程
- 多模型并行

## Core rules

- 每个节点必须属于泳道
- 跨泳道箭头尽量短
- 泳道标题固定
- 同一泳道保持一致阅读方向
