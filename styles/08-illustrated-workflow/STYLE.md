# Illustrated Workflow / 图文融合流程

流程节点结合设备、对象、数据或结果小图示

## Structural family

Hybrid visual workflow

## Best for

- Graphical abstract
- 实验-数据-模型
- 设备流程
- 结果摘要

## Core rules

- 图示必须有信息功能
- 文字更短
- 视觉元素风格统一
- 最终仍保持矢量和可编辑
