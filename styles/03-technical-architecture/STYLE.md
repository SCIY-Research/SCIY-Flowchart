# Technical Architecture / 工程系统架构

强调组件组成、接口与相互作用

## Structural family

System / block architecture

## Best for

- 实验系统
- 控制系统
- 软件架构
- CFD/ML pipeline

## Core rules

- 组件优先而非时间顺序
- 接口方向必须明确
- 允许内部子模块
- 输入输出放边缘
