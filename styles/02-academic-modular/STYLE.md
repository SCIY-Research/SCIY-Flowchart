# Academic Modular / 模块分区学术

按阶段或功能模块分区，适合复杂研究路线

## Structural family

Grouped modules / phases

## Best for

- 数学建模
- Methodology framework
- 多阶段研究
- 复杂技术路线

## Core rules

- 组间距大于组内距
- 组标题统一位置
- 跨组箭头走公共通道
- 组内可使用不同局部布局
