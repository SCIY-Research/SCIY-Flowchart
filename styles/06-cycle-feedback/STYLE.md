# Cycle & Feedback / 循环反馈优化

表达迭代、闭环控制、优化与复核

## Structural family

Cycle / feedback loop

## Best for

- 优化算法
- 参数迭代
- 闭环控制
- 模型复核

## Core rules

- 主流程清楚后再画回路
- 反馈线优先走外围
- 循环入口唯一且清晰
- 收敛/退出条件必须明确
