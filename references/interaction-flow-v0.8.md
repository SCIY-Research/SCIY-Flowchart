# SCIY Flowchart interaction flow v0.8

## Custom path
Input source → language/typography → choose 1 of 8 structure families → inspect 4 structure references → AI generates 4 original concepts → user selects concept → color choice (optional) → choose Quick / High-quality → formal vector drawing → QA → export.

Color choice options:
- Default academic palette
- Palette gallery
- Custom text / HEX / RGB
- Upload a color reference
- AI choose
- Skip = default

## One-click path
Input → infer language → AI selects structure family and one original concept → default academic palette → Quick mode → QA → export.

## Hard separation
- Structure references = structure ideas only.
- Palette gallery = color only.
- Neither layer should silently dictate the other.
