# SCIY One-click v0.9

- No style, palette, font, candidate count, nor render-mode questions.
- Use supplied text/image; keep graph topology, exact wording whenever readable.
- Determine language from input; default Latin Times New Roman and Chinese Source Han Sans SC or installed Noto Sans CJK SC.
- Auto choose one of eight composition categories by actual graph semantics, **not color**.
- Select exactly one concept (image generation if available, else one local SVG blueprint; never 4).
- Palette defaults to SCIY blue `#3C5488`, cyan `#4DBBD5`, teal `#00A087`.
- Execute Quick rendering, validating and delivering actual vector files.
- Never stop from image-generation network issues; at most one transient retry, then local fallback.
- Local gallery opening or new web research must not delay one-click.
