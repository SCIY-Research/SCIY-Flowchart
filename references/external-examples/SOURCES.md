# External reference gallery — Sources & Attribution (v0.7)

## Purpose

`STYLE-GALLERY.html` and `STYLE-GALLERY.md` use eight curated third-party academic/public examples as **temporary style-selection references**. They are not SCIY-owned templates. The four weaker references used in v0.6 (02/04/06/08) were replaced in v0.7 with higher-quality figures from peer-reviewed open-access papers.

The reference images are loaded from their original public URLs rather than copied into this package. The authoritative license is always the linked source page.

## Usage notice

- SCIY does not claim ownership of these third-party reference images.
- They are used only as temporary style-comparison references during early skill development.
- **Attribution alone does not replace compliance with the actual license.** Anyone republishing, redistributing, modifying, or commercially using a reference image must follow the linked source page's license terms.
- For open-access journal figures, always check whether the figure itself contains a separate third-party credit line; such a credit line may override the article-level license for that item.
- Final SCIY diagrams should be independently generated from the user's own content rather than copying the reference image's protected text, graphics, or exact composition.
- Future releases should gradually replace these temporary references with SCIY-generated examples.
