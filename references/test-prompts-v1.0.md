# Two-level workflow smoke scenarios

1. “调用技能绘制这篇论文”：输入已提供时不重复索要；先展示快速模式和自定义模式，不预设路线。
2. “直接调用快速模式”：AI分析内容并选择结构，一张蓝图后直接绘制、检验与交付；不展示4个候选，不询问全局还是分区。
3. “自定义模式”：先统一结构＋配色＋中文/英文/中英混排＋字体＋字号选择；选02-C＋P03后产生4个不同候选；只回复B时仅记录选图，然后询问全局绘制还是高质量分区重建。
4. 自定义选图后回答“全局绘制”：整图绘制并交付，仍属于自定义模式；不得把它称为进入快速模式。
5. 自定义选图后回答“高质量分区重建”：按所选蓝图进行实质性的语义分区矢量重建，不能只拆分拼回普通SVG。
6. 回答“B＋全局绘制”：已提供两个选择，直接执行，不重复询问绘制方式。
7. “AI自动选结构配色”：分析与比较结构，然后生成候选；不能替用户选择最终绘制方式。
8. “跳过候选”：选择合适蓝图后询问绘制方式，不强迫四个候选、不自动改成快速路线。
9. 快速路线输入三条并行研究分支：比较模块、架构、泳道等适配结构，不默认01线性图。纯顺序步骤允许有依据地选择01。
10. 图片服务失败：最多一次瞬时重试后提供诚实标注的SVG候选；不切换路线或绘制方式。

## Scientific and export checks
- 同一候选组保持相同科学依赖，区别在真实构图。
- 留出测试不回流训练；不补造样本、算法、年月或反馈。
- 运行check-semantics与validate-diagram，并查看实际导出图。
- 自定义全局和分区均输出真实可编辑矢量，AI位图不冒充最终矢量。
- 可运行scripts/release-check.py验证已有导出器；可选依赖缺失时诚实报告SKIP。

11. 用户只给“01-C＋P07”，此前没展示字体选项：保留结构与配色，仅补问字体字号，再生成候选，不重复询问已确认内容。
12. “01-C＋P07＋宋体/Times New Roman＋节点12pt”：保存typography并用于AI提示词和最终矢量，不再单独问字体。

13. 自定义输入中文论文但未选输出语言：在结构配色字体字号同一轮明确询问中文/英文/中英混排，不因源文是中文就默认中文；其他已选项保留。
14. 已明确英文：所有AI候选与矢量正文使用英文，不重复问语言；字体不能代替语言选择。
